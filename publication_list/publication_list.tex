\begin{itemize}[label={},leftmargin=3.2em,itemsep=2.5pt]

  cultures. Co-developed with Simon Rey.
  \item[\textbf{[S3]}] \textbf{mapof}. Python library for
  computing distances between elections and drawing maps of elections.
